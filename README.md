# 🧟 Zombie Escape — Zombie Survival Game LAB4

A 2D zombie survival game where players must fight off increasingly challenging waves of zombies, manage ammunition, protect their health, and survive as long as possible. The game features multiple zombie types, explosive barrels, and progressive difficulty to create an engaging survival experience.

🔗 **GitHub Repository:** [aryanmittal2107/25_zombie_escape](https://github.com/aryanmittal2107/25_zombie_escape)

---

## 🎮 Game Features

### ❤️ Player Health System
- Player starts with **3 HP**.
- Zombie contact reduces health by exactly 1 HP.
- A temporary invincibility period prevents repeated damage from a single encounter.
- The HUD displays the player's current health.
- The game ends when the player's health reaches zero.

### 🔫 Ammunition and Reload System
- Magazine capacity of **12 bullets**.
- Every shot consumes one bullet.
- Automatic reloading when the magazine becomes empty.
- Reload duration of exactly **2 seconds**.
- HUD indicators display ammunition and reload status.

### 💥 Explosive Barrels
- Four explosive barrels are placed in the game.
- Shooting a barrel triggers an explosion.
- Zombies within the explosion radius are destroyed.
- Exploded barrels are removed from the game.

### 🧟 Multiple Zombie Types

| Zombie Type | Health | Size | Speed |
|---|---:|---|---:|
| Normal Zombie | 3 HP | 30 × 30 | 1.5 |
| Fast Zombie | 1 HP | 20 × 20 | 3.0 |
| Tank Zombie | 6 HP | Larger than normal | Slower than normal |

Each zombie type introduces a different challenge, requiring players to adapt their survival strategy.

### 🌊 Wave Progression System
- The game progresses automatically when all zombies in the current wave are eliminated.
- Each new wave increases the number of zombies.
- Wave 1 starts with 4 zombies, Wave 2 with 5, and Wave 3 with 6.
- Fast zombies begin appearing from Wave 2.
- Tank zombies begin appearing from Wave 3.

### 📊 Heads-Up Display (HUD)
The in-game HUD displays:
- Player health
- Remaining ammunition
- Reload status
- Current wave
- Kill progress toward the next wave

---

## 🕹️ Gameplay

The objective is to survive successive waves of zombies while managing health and ammunition efficiently.

Players must eliminate zombies, use explosive barrels strategically, and adapt to increasingly difficult waves. Fast zombies test reaction speed, while tank zombies require more ammunition to defeat.
